# 电机CAN通讯协议控制指南 (V1.1)

## 一、通讯基础

- **通讯方式**: CAN总线（标准帧）
- **数据方向**: 主控 → 电机（控制/查询），电机 → 主控（反馈）

---

## 二、控制流程

### Step 1: 初始化配置

```
┌──────────────────────────────────────────────────────┐
│  上电 → 设置设备号 → 配置电机参数 → 配置轮径 → 锁定电机  │
└──────────────────────────────────────────────────────┘
```
#### 1.0 设置设备号
##### 1.0.0电机上电时会发来设备SN号
| **CAN ID** | `0x0312` |
| **数据长度** | 7 字节 |
| Data[0~6]：绑定的设备SN
这时候要设置设备号，发送如下
| **CAN ID** | `0x0313` |
| **数据长度** | 8 字节 |
| Data[0~6]：绑定的设备SN
  Data[7]：设备号
##### 1.0.1主动获取电机SN号
| **CAN ID** | `0x060D` |
| **数据长度** | 2 字节 |
| **Data[0]** | 设备类型 |
| **Data[1]** | `0` |

示例： 
收到电机发送的19 0C 03 07 93 2D 00
回应19 0C 03 07 93 2D 00 01
 
#### 1.1 配置电机参数（初始化）
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0316` |
| **数据长度** | 8 字节 |
| **Data[0~5]** | 配置内容 |
| **Data[6]** | bit7 = 方向位（正/反转） + 设备编号 |
| **Data[7]** | 设备号 |

示例：B4 BF CF AA 00 5F 01 01

#### 1.2 配置轮径
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0408` |
| **数据长度** | 4 字节 |
| **Data[0]** | 设备号 |
| **Data[1]** | `0x24` |
| **Data[2~3]** | 轮径值（单位: 0.01mm，对应 0.1mm 分辨率） |

> 需重复3次写入

#### 1.3 控制电机锁定
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0413` |
| **数据长度** | 5 字节 |
| **Data[0]** | `0x5A` = 上电锁定 / `0x4A` = 下电释放 |
| **Data[4]** | 设备号 |

---

### Step 2: 设置运动参数

#### 2.1 设置速度
**主速度：**
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0415` |
| **数据长度** | 5 字节 |
| **Data[0~3]** | 速度值 (s32)，单位: **0.1mm/s** |
| **Data[4]** | 设备号 |

**从速度：** CAN ID = `0x0418`，格式同上

#### 2.2 设置加速度
**主加速度：**
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0414` |
| **数据长度** | 5 字节 |
| **Data[0~3]** | 加速度值 (s32) |
| **Data[4]** | 设备号 |

**从加速度：** CAN ID = `0x0417`，格式同上

---

### Step 3: 发送目标位置（开始运动）

**设置目标位置（主）：**
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0416` |
| **数据长度** | 6 字节 |
| **Data[0~3]** | 目标位置 (s32)，单位: **0.1mm** |
| **Data[4]** | 设备号 |
| **Data[5]** | 目标类型 |

**目标类型说明：**
| Data[5]值 | 含义 |
|-----------|------|
| `0x00` | 相对位移 |
| `0x05` | 绝对位置 |
| `0x0A` | 归零/回零 |
| `0x0B` | 急停 |

**设置目标位置（从）：** CAN ID = `0x0419`，5字节，省略目标类型

---

### Step 4: 接收反馈

#### 4.1 剩余位移反馈
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0420 + 设备号` |
| **数据长度** | 8 字节 |
| **Data[0~3]** | 主通道位移 (s32) |
| **Data[4~7]** | 从通道位移 (s32) |

#### 4.2 参数设置ACK
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x041A` |
| **数据长度** | 2 字节 |

#### 4.3 力矩数据反馈
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0440 + 设备号` |
| **Data[2~3]** | 当前扭矩值 (s16) |

#### 4.4 心跳数据反馈
| 项目 | 值 |
|------|------|
| **CAN ID** | `0x0380 + 设备号` |

---

## 三、查询命令（均通过 0x0408 发送）

| 查询功能 | Data[0] | Data[1] | 返回ID | 返回内容 |
|---------|---------|---------|--------|---------|
| 当前温度 | 设备号 | `0x06` | `0x0409` | 温度 (单位: 0.1°C) |
| 当前位置 | 设备号 | `0x08` | `0x0409` | 位移 (单位: 0.1mm) |
| 状态 | 设备号 | `0x25` | `0x0409` | Bit0=位置，Bit1=零位 |
| 固件版本号 | 设备号 | — | `0x0409` | u32 版本号 |

---

## 五、错误码处理

| 错误码 | 含义 | 处理建议 |
|--------|------|---------|
| `0x0102` | 任务未完成/未到位 | 检查是否有机械阻挡 |
| `0x0104` | **堵转** | 立即停止，检查机械结构 |
| `0x0105` | **超温** | 停止运行，等待降温 |
| `0x0107` | **欠压** | 检查电源电压 |
| `0x0108` | **断线** | 检查CAN线连接 |

> 错误信息通过 CAN ID `0x0100 ~ 0x017F` 上报

# 电机配置参数定义 (0x0316) 完整解析

## 总览：8字节数据结构

```
can_send(0x0316, {Byte0, Byte1, Byte2, Byte3, Byte4, Byte5, Byte6, Byte7})
```

---

## 逐字节详解

### Byte0 — 极对数 + 其他参数
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
 ┌─────────────────────────┬─────────────────────┐
 │     (其他参数)           │   极对数(一般为4)     │
 └─────────────────────────┴─────────────────────┘
 参考值: 0xB4 = 1011_0100  →  极对数 = 0b100 = 4
```

---

### Byte1 — 速度环 PI 参数
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
 ┌───────────────────────┬───────────────────────┐
 │     速度P参数(高4位)    │    速度I参数(低4位)    │
 └───────────────────────┴───────────────────────┘
 参考值: 0xBF → 速度P = 0xB(11), 速度I = 0xF(15)
```

---

### Byte2 — 转矩环 PI 参数
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
 ┌───────────────────────┬───────────────────────┐
 │     转矩P参数(高4位)    │   转矩I参数(低4位)    │
 └───────────────────────┴───────────────────────┘
 参考值: 0xCF → 转矩P = 0xC(12), 转矩I = 0xF(15)
```

---

### Byte3 — 最大电流限制
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
 ┌───────────────────────┬───────────────────────┐
 │  顺时针最大电流(高4位)  │ 逆时针最大电流(低4位)  │
 └───────────────────────┴───────────────────────┘
 参考值: 0xAA → 顺时针 = 0xA(10), 逆时针 = 0xA(10)
```
> 两个方向电流相同，表示双向对称限流

---

### Byte4 — 刹车与阻尼
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2    Bit1  Bit0
 ┌─────────────────────────────┬────┬──────────────┐
 │          (保留)              │刹车│    阻尼       │
 └─────────────────────────────┴────┴──────────────┘
 参考值: 0x00 → 刹车=0(关闭), 阻尼=0(无阻尼)
```

| 刹车(Bit2) | 含义 |
|-----------|------|
| 0 | 刹车关闭 |
| 1 | 刹车使能 |

| 阻尼(Bit1~0) | 含义 |
|-------------|------|
| 0b00 | 无阻尼 |
| 0b01~0b11 | 阻尼等级递增 |

---

### Byte5 — 速度/转矩 D参数
```
  Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
 ┌───────────────────────┬───────────────────────┐
 │    速度D参数(高4位)     │   转矩D参数(低4位)     │
 └───────────────────────┴───────────────────────┘
 参考值: 0x5F → 速度D = 0x5(5), 转矩D = 0xF(15)
```

---

### Byte6 — 控制模式与马达号
```
  Bit7       Bit6          Bit5              Bit4           Bit3~Bit0
 ┌────┬──────────────┬──────────────────┬──────────────────┬──────────┐
 │方向│往返模式自动解锁│自动返回剩余位移   │自动返回剩余力矩   │  马达号   │
 └────┴──────────────┴──────────────────┴──────────────────┴──────────┘
```

| 位 | 值 | 含义 |
|---|---|------|
| **Bit7** | `0` | 顺时针（正对电机轴） |
| **Bit7** | `1` | 逆时针 |
| **Bit6** | `0/1` | 往返模式自动解锁 |
| **Bit5** | `0` | **使能**自动返回剩余位移 |
| **Bit5** | `1` | 关闭 |
| **Bit4** | `0` | **使能**自动返回剩余力矩 |
| **Bit4** | `1` | 关闭 |
| **Bit3~0** | | 马达号(0~15) |

---

### Byte7 — 设备号
```
设备号：CAN总线上的设备地址
```

---

## 完整参考配置示例

```c
// 使用参考默认值
uint8_t config[8] = {
    0xB4,   // Byte0: 极对数=4
    0xBF,   // Byte1: 速度P=11, 速度I=15
    0xCF,   // Byte2: 转矩P=12, 转矩I=15
    0xAA,   // Byte3: 顺时针电流=10, 逆时针电流=10
    0x00,   // Byte4: 刹车关闭, 阻尼=0
    0x5F,   // Byte5: 速度D=5, 转矩D=15
    0x01,   // Byte6: 顺时针, 自动返回使能, 马达号=1
    0x01    // Byte7: 设备号=1
};

can_send(0x0316, config);
```

### 修改方向为逆时针的例子：
```c
// Byte6: bit7=1(逆时针), bit5=0(返回位移), bit4=0(返回力矩), 马达号=1
config[6] = 0x81;  // 1000_0001
//           │              │
//           逆时针         马达号1
```

## PID 参数总结

```
         ┌─────────┬─────────┬─────────┐
         │    P    │    I    │    D    │
 ┌───────┼─────────┼─────────┼─────────┤
 │ 速度环 │Byte1高4位│Byte1低4位│Byte5高4位│
 │  参考  │  0xB=11 │  0xF=15 │  0x5=5  │
 ├───────┼─────────┼─────────┼─────────┤
 │ 转矩环 │Byte2高4位│Byte2低4位│Byte5低4位│
 │  参考  │  0xC=12 │  0xF=15 │  0xF=15 │
 └───────┴─────────┴─────────┴─────────┘
```

> 💡 如果电机运行时有抖动/震荡，调小P值；响应慢则调大P值

## 运行参数单位对照

| 参数 | 单位 | 备注 |
|------|------|------|
| **轮径** | **0.01mm** | 轮径与位移成正比关系 |
| **位移** | **0.1mm** | 轮径放大n倍→位移也放大n倍 |
| **速度** | **0.1mm/s** | |
| **加速度** | **0.1mm/s²** | |

> ⚠️ **重要**: 轮径和位移是**联动**的，修改轮径后要相应调整位移参数！
